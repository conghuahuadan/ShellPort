# 我做了一个 SSH 桌面工具，把终端、文件管理和系统监控放进同一个工作区

连接服务器之后，你通常会做什么？

打开终端看日志，切到文件工具上传配置，再查看 CPU、内存和网络状态。如果同时处理几台机器，还要在不同连接和窗口之间来回切换。

这些操作经常发生在同一次排查或部署中，所以我做了一个桌面工具 **ShellPort**，把 SSH 终端、本机终端、文件管理和系统监控放进同一个工作区。

目前提供 **macOS 和 Windows** 的公开安装包，覆盖 Intel / AMD x64、Apple Silicon 和 Windows ARM64 设备。先放一张工作区截图：

![ShellPort 工作区：左侧文件树，中间 SSH 终端，右侧系统监控](https://conghuahuadan.github.io/ShellPort/assets/workspace.webp)

## 从一次服务排查说起

假设服务器上的某个接口突然变慢，你可能需要同时做几件事：

- 持续观察服务日志，看有没有异常或超时。
- 执行命令，检查进程和连接情况。
- 查看 CPU、内存、网络和磁盘状态，辅助判断问题方向。
- 找到远程配置文件，确认当前配置。

在 ShellPort 里，终端、文件和监控可以放在同一个工作区。查看日志时，旁边保留资源状态；需要处理文件时，也能直接打开文件侧栏。

它想改善的是这个很具体的过程：**连接上服务器之后，让接下来的操作更连贯。**

## 终端分屏：一边看日志，一边执行命令

终端支持多标签、标签拖动排序，以及横向、纵向分屏。每个分屏有独立的终端连接与输入，同一标签内共享文件和监控侧栏。

![ShellPort 双终端分屏，文件与监控侧栏保持可见](https://conghuahuadan.github.io/ShellPort/assets/split-terminal.webp)

比如排查服务时，一个终端持续查看日志，另一个终端执行检查命令。这样可以把关注的输出留在眼前，减少反复切换。

终端还支持查找当前屏幕已经保留的输出内容。比如刚才输出里出现过某条报错，可以直接搜索定位；它检索的是当前终端缓冲，不是跨会话的命令历史。

## 文件管理：在终端旁处理远程文件

部署项目时，执行命令和处理文件通常是连在一起的：上传文件、检查目录、查看配置，然后回到终端继续操作。

ShellPort 提供了 SFTP 文件侧栏，支持：

- 浏览远程文件树，收藏常用文件或目录。
- 进行文件、目录操作和权限编辑。
- 上传、下载文件，查看实际传输速度，暂停、继续、重试或取消传输。
- 从系统拖入文件，确认目标后上传，也可以将文件夹打包上传。
- 直接编辑远程文本，保存前检查文件是否已被其他操作修改。

如果经常进入固定的日志目录、配置目录或部署目录，可以把它们收藏起来。后续再连接这台主机时，访问这些目录会更方便。

文本编辑支持最多 **2 MiB 的普通文本文件**。断线后草稿仍会保留在当前应用中，也可以将当前内容导出为副本；保存遇到版本冲突时会提示处理，避免直接覆盖别人的修改。

## 本机终端：本地操作也有文件和监控侧栏

有些工作需要先在本机整理文件，再连接服务器；有时只是想打开一个本地 Shell 执行命令。

从主机页可以直接打开本机终端，无需创建 SSH 主机。它使用原生 Shell 和 PTY，旁边的文件树、文本编辑和系统监控也读取本机实际数据。

本机工作区与远程连接一样支持分屏，方便并排操作。本机文件和当前标签内的本机收藏不进入配置备份或云同步。

## 系统监控：在命令输出旁多保留一份信息

只看日志，有时还不足以判断问题。

例如请求超时时，资源占用是否同时发生变化？执行某项任务时，磁盘或网络是否出现明显波动？把这些信息和终端输出放在一起，更方便交叉观察。

ShellPort 的监控侧栏可以查看 CPU、内存、网络和磁盘状态，并进一步查看进程、连接和文件系统。

具体能获取哪些指标，取决于目标系统及当前账号权限。它适合在日常远程操作时提供辅助信息。

## 主机多了，也需要好好整理

开发环境、测试环境、生产环境，再加上个人服务器，连接列表很容易越积越长。

ShellPort 支持主机分组、搜索和排序，可以按环境或用途整理连接，也能按名称、地址或用户名查找。连接前可以进行诊断，断线后可以手动重连。

认证方式支持密码和 OpenSSH/PEM 私钥。私钥可以选择文件、拖入或粘贴内容，加密保存在本机；带口令的私钥在连接时输入口令，口令不会保存。

当前首次 SSH 连接或连接测试会自动记录该地址与端口的主机密钥，不弹出指纹确认。之后如果密钥变化，连接会被阻止；主机指纹只保存在本机。

![ShellPort 浅色主题下的主机分组、搜索与主机信息卡片](https://conghuahuadan.github.io/ShellPort/assets/hosts-light.webp)

外观上支持深色、浅色主题和中英文界面，也可以调整终端字体和快捷键，按自己的习惯配置。

## 换设备时，配置怎么带走？

ShellPort 支持按范围导出、导入本地配置。导入时先预检冲突，再选择应用的内容；导入或恢复前会保留设备加密的恢复快照，便于找回之前的配置。

如果需要在设备之间同步，也可以接入自己的 **HTTPS WebDAV 服务**，加密同步所选主机与分组、收藏、偏好，以及可选的登录密码，并创建或恢复云端备份。

WebDAV 默认关闭，无需注册 ShellPort 账号，不配置也可以正常使用终端。确认同步范围和首次处理策略后，授权与基线有效且无冲突时，可以在启动和正常退出时同步，使用中也可以手动同步。遇到冲突需要确认处理方式。当前未开放内置云服务或会员服务。

这里有几个与迁移有关的细节：

- **SSH 私钥加密保存在本机，不包含在导出备份或云同步中**，换设备后需要重新提供；私钥口令也不会进入备份或同步。
- 登录密码默认不纳入备份、同步，需要显式勾选对应范围。
- WebDAV 同步文档整体加密；本地 JSON 备份中的主机地址等配置仍是明文，密码字段使用内置便携密钥加密，不等同于主密码保护，需要妥善保管备份文件。
- 迁移的是配置，运行中的终端、传输和监控不会随配置恢复，本机文件与本机收藏也不随配置迁移。

## 日常使用：保留工作区，也方便更新和排障

应用会记忆窗口位置和尺寸。按需选择关闭到后台后，可以从系统托盘或 macOS 菜单栏恢复原来的工作区；真正退出时则会检查未保存内容和受影响的操作。

应用内支持检查、下载、校验并安装正式版本更新。遇到问题时，可以在设置中查看或导出本地诊断日志，配合复现步骤反馈。

## 如何开始使用

打开 [最新版本下载页](https://github.com/conghuahuadan/ShellPort/releases/latest)，在 Assets 中选择对应设备的安装包：

| 设备 | 文件名关键词 | 安装包 |
| --- | --- | --- |
| Mac，Apple Silicon（M 系列） | `macos-arm64` | `.dmg` |
| Mac，Intel | `macos-amd64` | `.dmg` |
| Windows，Intel / AMD x64 | `windows-amd64` | `-setup.exe` 或 `.zip` |
| Windows，ARM64 | `windows-arm64` | `-setup.exe` 或 `.zip` |

安装后，可以按下面的顺序体验：

1. 点击“新建主机”，填写地址、端口、用户名和认证信息。
2. 连接主机，进入终端工作区；首次连接会自动记录主机密钥。
3. 展开文件与监控侧栏，试试在同一个工作区查看日志、浏览目录和观察资源状态。
4. 需要同时执行其他命令时，再添加终端分屏。

安装前请阅读对应版本的发布说明。当前项目说明中，macOS 安装包尚未完成 Developer ID 签名与 Apple 公证，Windows 安装包未签名，首次打开可能出现系统安全提示；具体状态和系统要求以对应版本说明为准。发布附件中的 `SHA256SUMS.txt` 提供安装包校验值。

## 当前还有哪些边界？

公开下载包目前面向 macOS 和 Windows，暂无 Linux 安装包。远程监控指标和文件权限操作取决于目标系统与当前账号权限。

SSH 连接目前不支持跳板机、SSH agent、硬件密钥、键盘交互式 MFA 或断线自动重连。如果你的日常工作依赖这些能力，使用前可以先确认是否符合需求。
