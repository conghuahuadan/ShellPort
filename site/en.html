A FEW MORE THINGS YOU MIGHT WANT TO KNOW

Common questions.

Found an issue or have an idea?
Tell us on GitHub ↗

Do I need cloud sync to use ShellPort?

No ShellPort account is required. WebDAV is off by default and uses your chosen HTTPS service. Confirm the scope and initial strategy to enable startup and normal-exit sync when authorization is valid and no conflicts occur. Manual sync is available; conflicts require confirmation. Built-in cloud and membership services are not currently available.

Can I use a local terminal too?

Yes. Open a native local terminal from the hosts page without creating an SSH host. File browsing, text editing, and monitoring use local data. Local files and per-tab local bookmarks are excluded from configuration backups and sync.

Are private keys included in sync or backups?

No. Private keys are encrypted locally and excluded from exports and sync; passphrases are used only for the current operation. Login passwords are excluded by default and require explicit selection. WebDAV documents are encrypted as a whole using a key derived from the WebDAV password; this does not guarantee that the provider cannot decrypt them. Local JSON leaves host addresses and other configuration readable; password fields use a built-in portable key, which is not master-password protection. Keep backups safe.

Where can I find older versions and release notes?

Find past versions, release notes, and packages in Releases. You can also share issues and ideas on GitHub.

What should I include in an issue report?

Include your operating system, processor architecture, ShellPort version, reproduction steps, and expected and actual results. Screenshots or sanitized logs help. Do not upload passwords, private keys, databases, local encryption key files, or unsanitized logs.

Does the first connection ask me to confirm a fingerprint?

The first SSH connection or connection test automatically records the host key for that address and port, without a confirmation dialog. Later key changes block the connection. Host fingerprints stay on the device and are excluded from configuration sync.

Does command completion execute commands?

No. It appears at recognized command input positions and only inserts a command name. Press Enter again to execute. It does not generate AI commands or guarantee coverage of temporary aliases, functions, or PATH changes in the active shell. Some commands may have no bundled description.

What are the current limits?

Public packages target macOS and Windows; no Linux package is currently provided. Text editing supports regular text files up to 2 MiB. Monitoring and permission operations depend on the system and access rights. Jump hosts, SSH agents, hardware keys, keyboard-interactive MFA, and automatic reconnection are not currently supported.
